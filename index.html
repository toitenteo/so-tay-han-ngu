Mở toàn màn hình như ứng dụng độc lập, không cần kho ứng dụng

iPhone / iPad (Safari)
  1. Mở đường link GitHub Pages bằng trình duyệt Safari.
  2. Chạm biểu tượng Chia sẻ (ô vuông có mũi tên lên) ở thanh dưới.
  3. Chọn Thêm vào MH chính (Add to Home Screen) → nhấn Thêm.
Android (Chrome)
  1. Mở đường link GitHub Pages bằng trình duyệt Chrome.
  2. Chạm biểu tượng 3 chấm dọc (⋮) ở góc trên bên phải.
  3. Chọn Thêm vào màn hình chính hoặc Cài đặt ứng dụng.
